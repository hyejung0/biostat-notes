1 \(\sigma\)-algebras and their generators

This section introduces \(\sigma\)-algebras, the foundational object of measure theory and probability.

A \(\sigma\)-algebras specifies which subsets of a space are allowed to be measured (i.e., assigned probabilities or measures).

1.1 Notations

  • \(\mathbb{N}\): Set of natural numbers 1,2, … (excluding 0)
  • \(\mathbb{Z}\): Set of whole numbers
  • \(\mathbb{Q}\): Set of rational numbers
  • \(\mathbb{R}\): Set of real numbers
  • \(\bar{\mathbb{R}}\) = extended or compactified number line. Includes \(\infty\) and \(- \infty\).
    • \(a + (\pm \infty) = (\pm \infty) + a = \pm \infty\) for \(a \in \mathbb{R}\).
    • \((+ \infty) + (+ \infty) = +\infty\)
    • \((- \infty) + (-\infty) = -\infty\) -typical in measure theory: \(0 \cdot (\pm \infty) = (\pm \infty) \cdot 0 = 0\), which mean that the product \(a \cdot b\) is defined for all \(a, b \in \bar{\mathbb{R}}\).
  • \(A := B\) or \(B=:A\) : the equation is the definition of \(A\) in terms of B
  • The \(<\) (resp., \(\leq\)) relation in \(\mathbb{R}\) is extended to \(\bar{\mathbb{R}}\) via the decree \(-\infty < a < + \infty\) for all \(a \in \mathbb{R}\).
  • \(\mathbb{Z}_+\): Set of all non-negative whole numbers
  • \(\mathbb{Q}_+\): Set of all non-negative rational numbers
  • \(\mathbb{R}_+\): Set of all non-negative real numbers
  • \(\bar{\mathbb{R}}_+\): Set of all \(a\ in \bar{\mathbb{R}}\) with \(0 \leq a \leq + \infty\)
  • Intervals in \(\bar{\mathbb{R}}\): \([a, b]\), \(]a, b[\), \(]a, b]\), \([a, b[\).
  • \((a,b)\): ordered pair with first element \(a\), second element \(b\).

For every pair of elements in \(a, b \in \bar{\mathbb{R}}\),

  • \(a \vee b := \text{max } \{a, b\}\)
  • \(a \wedge b := \text{min } \{a, b\}\)
  • If \(a^+ := a \vee 0\) and \(a^- := (-a)^+ = -(a \wedge 0)\), then \(|a| = a \vee (-a) = a^+ + a^-\), and \(a = a^+ - a^-\).
    • \(a^+ \geq 0\) and \(a^- \geq 0\).
  • For finitely many \(a_1, \cdots, a_n \in \bar{\mathbb{R}}\),
    • \(a_1 \vee ... \vee a_n := \text{max } \{ a_1, \cdots, a_n\}\)
    • \(a_1 \wedge ... \wedge a_n := \text{min } \{ a_1, \cdots, a_n\}\)

Set-theoric operations. Let \(A\) and \(B\) be sets.:

  • \(\cup\): union
  • \(\cap\): intersection
  • \(\complement\): complementation
  • \(A \subset B\): inclusion
  • \(A \cap \complement B\): difference set. The set of all \(a \in A\) such that \(x \notin B\).
  • \(\emptyset\): empty set
  • \(A \cap B = \emptyset\): \(A\) and \(B\) are disjoint.
  • \(\mathscr{P}(\Omega)\) of a set \(\Omega\): the set of all subsets of \(\Omega\), including the empty set.
  • A set \(A\) is called countable if it is either finite or denumberably infinite.
  • A set \(A\) is called non-denumerable or uncountable if is neither finite nor denumberable.

Mappings of a set \(A\) into a set \(B\):

  • \(f: A \rightarrow B\) or \(x \mapsto f(x)\) (with \(x \in A\)).

Sequence in a set \(A\)

  • is a mapping \(f: \mathbb{N} \rightarrow A\)
  • \((a_n)\): mapping \(f\)

Size of a set:

  • finite: A set \(A\) is finite if it had only finitely many elements, e.g., \(\{2,5,9\}, \emptyset\).
  • countably infinite: A set \(A\) is countably infinite (= denumerably infinite) if you can list its elements as a sequence \[a_1, a_2, a_3, \cdots\] with no missing elements. Formally: there exists bijection between \(A\) and \(\mathbb{N} = \{1, 2, 3, \cdots\}\).
    • Ex) the even numbers \(\{2, 4, 6, \cdots\}\), The integers \(\{0,1, -1, 2, -2, 3, -3, \cdots\}\), and the rational numbers \(\mathbb{Q}\) (nontrivial, but true).
  • countable: either finite or countably infinite.
  • uncountable: A set \(A\) is uncountable if it is not finite and not denumerably infinite (i.e., there is no way to list all its elements \(a_1, a_2, \cdots\) without missing some). Bauer calls it “denumerable” or “uncountable.”
    • Ex) Real numbers \(\mathbb{R}\), any interval \([a, b] \subset \mathbb{R}\)
  • Let \(\Omega\) be the ambient set (“universe”) and \(A \subset \Omega\). The complement is \(A^c := \Omega \backslash A\).
    • A set \(A\) is co-countable if its complement \(A^c\) is countable. So it means “all of \(\Omega\) except maybe countably many points.”
    • A set \(A\) is co-finite if \(A^c\) is finite. So it means “all of \(\Omega\) except maybe finitely many points.”

Let \(\Omega\) be an arbitrary set.

Definition 1 (\(\sigma\)-algebra)

A system \(\mathscr{A}\) of a subsets of a set \(\Omega\) is called a \(\sigma\)-algebra (in \(\Omega\)) if it has the following properties:

  1. Whole space included \[ \Omega \in \mathscr{A} \]

  2. Closed under complements

    \[ \text{If } A \in \mathscr{A}, \text{then } A^c = \Omega \setminus A \in \mathscr{A}\]

  3. Closed under countable unions

    If \(A_1, A_2, \dots \in \mathscr{A}\), then \[ \bigcup_{n=1}^\infty A_n \in \mathscr{A} \]

1.2 Immediate consequences

From the definition alone, every \(\sigma\)-algebra is automatically closed under:

  • The empty set: \(\emptyset \in \mathscr{A}\)
  • Countable intersections: \((a_n)_{n \in \mathbb{N}} \subset \mathscr{A} \Rightarrow \bigcap\limits_{n \in \mathbb{N}} A_n \in \mathscr{A}\)
  • Finite unions and intersections
  • Set differences: \(A, B \in \mathscr{A} \Rightarrow A\backslash B = A \cap \complement B \in \mathscr{A}.\)

These follow from De Morgan’s laws and complement closure.

Note: \(\mathscr{P}(\Omega)\) is also a \(\sigma\)-algebra.

1.3 Interpretation in probability

  • \(\Omega\) : all possible outcomes
  • \(\mathscr{A}\) : all events to which probabilities can be assigned
  • A probability measure is defined only on sets in \(\mathscr{A}\)

A \(\sigma\)-algebra answers the question:

Which events are we allowed to talk about probabilistically?

1.4 Important clarification

  • Saying \(\Omega \in \mathscr{A}\) means the set \(\Omega\) itself is an element of the collection.
  • It does not mean that \(\Omega\) can be constructed from unions of other sets.
  • \(\sigma\)-algebras are about membership and closure, not construction outside the collection.

1.5 Example: Finite sample space

Let \[ \Omega = \{0, -1, 1\} \]

Start with a single set Assume the \(\sigma\)-algebra contains: \[ \{0\} \]

Closure under complements forces: \[ \{0\}^c = \{-1, 1\} \]

By definition, a \(\sigma\)-algebra must also contain: \[ \Omega = \{0, -1, 1\}, \quad \emptyset \]

Resulting \(\sigma\)-algebra \[ \sigma(\{0\}) = \big\{ \emptyset,\ \{0\},\ \{-1,1\},\ \{0,-1,1\} \big\} \]

This is a valid \(\sigma\)-algebra.

1.6 Example of a non–\(\sigma\)-algebra

The collection \[ \{\emptyset,\ \{0\},\ \{-1\},\ \{1\},\ \{-1,1\},\ \Omega\} \] is not a \(\sigma\)-algebra, because:

  • The complement of \(\{-1\}\) is \(\{0,1\}\), which is missing
  • Closure under complements fails

1.7 Generating stuff

Theorem 1 The intersection \(\cap_{i \in I} \mathscr{A}_i\) of any family \((\mathscr{A}_i)_{i \in I}\) of \(\sigma\)-algebras in a common set \(\Omega\) is itself a \(\sigma\)-algebra in \(\Omega\).

Theorem 1 leads to conclusion that for every system \(\mathscr{E}\) of subsets of \(\Omega\), there is a smallest \(\sigma\)-algebra \(\boldsymbol{\sigma}(\mathscr{E})\) which contains \(\mathscr{E}\). That is, \(\boldsymbol{\sigma}(\mathscr{E})\) is a \(\sigma\)-algebra in \(\Omega\) with the defining properties:

  1. \(\mathscr{E} \subset \boldsymbol{\sigma}(\mathscr{E})\)
  2. for every \(\sigma\)-algebra \(\mathscr{A}\) in \(\Omega\), \(\boldsymbol{\sigma}(\mathscr{E}) \subset \mathscr{A}\).
  • \(\boldsymbol{\sigma}(\mathscr{E})\) is called the \(\sigma\)-algebra generated by \(\mathscr{E}\) (in \(\Omega\))
  • \(\mathscr{E}\) is called a generator of \(\boldsymbol{\sigma}(\mathscr{E})\).

1.8 Generated \(\sigma\)-algebras

Given any collection of sets \(\mathscr{S} \subset \mathscr{P}(\Omega)\), the \(\sigma\)-algebra generated by \(\mathscr{S}\) is defined as:

\[ \sigma(\mathscr{S}) = \bigcap \left\{ \mathscr{A} : \mathscr{A} \text{ is a $\sigma$-algebra and } \mathscr{S} \subset \mathscr{A} \right\} \]

Key idea:

  • The intersection of \(\sigma\)-algebras is again a \(\sigma\)-algebra
  • Therefore, the smallest \(\sigma\)-algebra containing \(\mathscr{S}\) always exists

1.9 Rings

Definition 2 (Ring)

A system \(\mathscr{R}\) of a subsets of a set \(\Omega\) is called a ring (in \(\Omega\)) if it has the following properties:

  1. \(\emptyset \in \mathscr{A}\)

  2. \(A, B \in \mathscr{R} \Rightarrow A\backslash B \in \mathscr{R}.\)

  3. \(A, B \in \mathscr{R} \Rightarrow A \cup B \in \mathscr{R}.\)

If in addition,

\[\Omega \in \mathscr{R}\]

then \(\mathscr{R}\) is called algebra (in \(\Omega\)).

1.10 Symmetric difference

For sets \(A\) and \(B\),

\[A \triangle B := ( A \backslash B) \cup ( B \backslash A)\] is called their symmetric difference. Symmetric difference obeys the following rules of calculation :

  1. \(A \triangle B = B \triangle A\)
  2. $ (A B) C = A (B C)$
  3. \(A \triangle A = \emptyset; \quad A \triangle \emptyset = A\)
  4. \(\complement A \triangle \complement B = A \triangle B\)
  5. \((A \triangle B) \cap C = (A \cap C) \triangle (B \cap C)\)
  6. \(\left( \bigcup_{n \in \mathbb{N}}A_n\right) \triangle \left( \bigcup_{n \in \mathbb{N}}B_n\right) \subset\bigcup_{n \in \mathbb{N}} \left( A_n \triangle B_n \right)\)

(for arbitrary sequences of \((A_n)\) and \((B_n)\) of sets).

A subset \(\mathscr{N}\) of a ring \(\mathscr{R}\) in a set \(\Omega\) is called an ideal if it satisfies

  1. \(\emptyset \in \mathscr{N}\)
  2. \(N \in \mathscr{N}, M \in \mathscr{R}, M \subset N \Rightarrow M \in \mathscr{N}.\)
  3. \(M, N \in \mathscr{N} \Rightarrow M \cup N \in \mathscr{N}.\)

1.11 Conceptual takeaway

A \(\sigma\)-algebra is:

The collection of events for which probability (or measure) is defined,
closed under complement and countable combination.

In statistics and probability, \(\sigma\)-algebras encode information:

  • What can be observed
  • What questions can be asked
  • What probabilities are meaningful

Let $\Omega$ be an arbitrary set.

::: {#def-1.1}
**($\sigma$-algebra)**

A system $\mathscr{A}$ of a subsets of a set $\Omega$ is called a *$\sigma$-algebra* (in $\Omega$) if it has the following properties:

1. **Whole space included**
   $$
   \Omega \in \mathscr{A}
   $$

2. **Closed under complements**

   $$ \text{If } A \in \mathscr{A}, \text{then } A^c = \Omega \setminus A \in \mathscr{A}$$

3. **Closed under countable unions**

   If $A_1, A_2, \dots \in \mathscr{A}$, then
   $$
   \bigcup_{n=1}^\infty A_n \in \mathscr{A}
   $$
:::

- The empty set: $\emptyset \in \mathscr{A}$

- Finite unions and intersections
- Set differences: $A, B \in \mathscr{A} \Rightarrow A\backslash B = A \cap \complement B \in \mathscr{A}.$

These follow from De Morgan’s laws and complement closure.

Note: $\mathscr{P}(\Omega)$ is also a $\sigma$-algebra.

- $\Omega$ : all possible outcomes
- $\mathscr{A}$ : all **events** to which probabilities can be assigned

A $\sigma$-algebra answers the question:

> *Which events are we allowed to talk about probabilistically?*

## Generating stuff

::: {#thm-1.2}

The intersection $\cap_{i \in I} \mathscr{A}_i$ of any family $(\mathscr{A}_i)_{i \in I}$ of $\sigma$-algebras in a common set $\Omega$ is itself a $\sigma$-algebra in $\Omega$.

:::

@thm-1.2 leads to conclusion that for every system $\mathscr{E}$ of subsets of $\Omega$, there is a smallest $\sigma$-algebra $\boldsymbol{\sigma}(\mathscr{E})$ which contains $\mathscr{E}$. That is, $\boldsymbol{\sigma}(\mathscr{E})$ is a $\sigma$-algebra in $\Omega$ with the defining properties:

(i) $\mathscr{E} \subset \boldsymbol{\sigma}(\mathscr{E})$
(ii) for every $\sigma$-algebra $\mathscr{A}$ in $\Omega$, $\boldsymbol{\sigma}(\mathscr{E}) \subset \mathscr{A}$.


- $\boldsymbol{\sigma}(\mathscr{E})$ is called the *$\sigma$-algebra generated by* $\mathscr{E}$ (in $\Omega$)
- $\mathscr{E}$ is called a *generator* of $\boldsymbol{\sigma}(\mathscr{E})$.

## Generated $\sigma$-algebras

Given any collection of sets $\mathscr{S} \subset \mathscr{P}(\Omega)$, the **$\sigma$-algebra generated by $\mathscr{S}$** is defined as:

$$
\sigma(\mathscr{S}) =
\bigcap \left\{
\mathscr{A} : \mathscr{A} \text{ is a $\sigma$-algebra and } \mathscr{S} \subset \mathscr{A}
\right\}
$$

Key idea:

- The intersection of $\sigma$-algebras is again a $\sigma$-algebra
- Therefore, the **smallest $\sigma$-algebra containing $\mathscr{S}$** always exists

## Rings 

::: {#def-1.3}
**(Ring)**

A system $\mathscr{R}$ of a subsets of a set $\Omega$ is called a *ring* (in $\Omega$) if it has the following properties:

1. $\emptyset \in \mathscr{A}$

2. $A, B \in \mathscr{R} \Rightarrow A\backslash B \in \mathscr{R}.$

3. $A, B \in \mathscr{R} \Rightarrow A \cup B \in \mathscr{R}.$
:::


If in addition, 

$$\Omega \in \mathscr{R}$$

then $\mathscr{R}$ is called *algebra* (in $\Omega$).


---

## Symmetric difference

For sets $A$ and $B$, 

$$A \triangle B := ( A \backslash B) \cup ( B \backslash A)$$
is called their *symmetric difference*. Symmetric difference obeys the following rules of calculation :

1. $A \triangle B = B \triangle A$
2. $ (A \triangle B) \triangle C = A \triangle (B  \triangle C)$
3. $A  \triangle A = \emptyset; \quad A  \triangle \emptyset = A$
4. $\complement A  \triangle \complement B = A  \triangle B$
5. $(A \triangle B) \cap C = (A \cap C) \triangle (B \cap C)$
6. $\left( \bigcup_{n \in \mathbb{N}}A_n\right) \triangle \left( \bigcup_{n \in \mathbb{N}}B_n\right) \subset\bigcup_{n \in \mathbb{N}} \left( A_n \triangle B_n \right)$

(for arbitrary sequences of $(A_n)$ and  $(B_n)$ of sets).



A subset $\mathscr{N}$ of a ring $\mathscr{R}$ in a set $\Omega$ is called an *ideal* if it satisfies 

1. $\emptyset \in \mathscr{N}$
2. $N \in \mathscr{N}, M \in \mathscr{R}, M \subset N \Rightarrow M \in \mathscr{N}.$
3. $M, N \in \mathscr{N} \Rightarrow M \cup N \in \mathscr{N}.$

---

## Conceptual takeaway

A $\sigma$-algebra is:

> **The collection of events for which probability (or measure) is defined**,  
> closed under complement and countable combination.

In statistics and probability, $\sigma$-algebras encode **information**:

- What can be observed
- What questions can be asked
- What probabilities are meaningful
